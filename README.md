# 📐 Angle Lock

A Geometry Dash Geode mod that allows players to lock their icon at a custom angle.

## Features

- Lock your icon at a custom angle
- Visual-only rotation
- No gameplay modifications
- Supports Geometry Dash 2.208
- Built using Geode

## Planned Features

- Pause menu angle selector
- Saved angle settings
- Preset angles (0°, 45°, 90°, 135°, 180°)
- Per-gamemode angle settings
- Quick enable/disable toggle
- Custom angle input

## Description

Angle Lock is a visual Geometry Dash mod that allows players to keep their icon rotated at a selected angle. This mod does not modify gameplay or hitboxes and is intended purely for visual customization.
